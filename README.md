## 9929 是什么线路？和普通欧洲 VPS 的区别在哪

9929 是中国联通的精品承载网（联通 A 网，AS9929），主要承接国际和国内跨地市的专线业务，常用于企业宽带和 IDC，基本不对家庭宽带开放。普通欧洲 VPS 走的是联通 169 网（AS4837），也就是普通家宽在用的那张网。两者承载的流量类型不同，价格和体验的差距就来自这里，也是 9929 机型普遍比同配置普通机型贵的原因。

联通骨干网实际有三张：AS4837（169 网，普通家宽和常规直连）、AS9929（A 网，企业专线承载）、AS10099（中国联通国际，负责国际段）。联通精品线路的完整路径是 AS4837 → AS9929 → AS10099：去程从 169 网出境，国际段走联通国际，入境后再落到 9929。有博主对悉尼 9929 机型跑过 traceroute，能清楚看到流量先进香港的 AS10099，再转广州、北京的 AS9929，中间没有绕第三方运营商。

搬瓦工给这条荷兰线路的定位是 China Unicom Premium（联通高级线路），官方宣传口径是“堪比电信 CN2 GIA”。是否真堪比得看实测，但它是搬瓦工在 CN2 GIA 之外、面向联通方向的主力优化线路，这一点没有争议。

顺带说下 9929 的分布。这两年这条线已经铺得很开：美国洛杉矶、德国法兰克福、英国伦敦（伦敦 IP 经法兰克福节点落地）、悉尼、马来西亚、新加坡都有商家在做。机房真正落在荷兰阿姆斯特丹的相对少见，这正是搬瓦工这条线的差异点。

## 哪些人适合买荷兰 9929 VPS，哪些人没必要

适合的是三类人：本地是联通或电信、在意回程质量的；业务必须落在荷兰或西北欧、对 IP 归属地有要求的；需要大带宽大流量做中转的。移动网络为主、纯图便宜、轻度使用的用户，不必上这套。

联通和电信用户受益最直接。9929 的优化重心就在这两个方向：美国 9929 机型实测里，电信、联通回程走 AS9929，能跑满 50Mbps 带宽；法兰克福 9929 机型实测电信平均延迟 158ms、联通 146.9ms、零丢包。

移动方向要单独说。同类 9929 机型上，移动有的走自家的 CMIN2，有的出现单点丢包（法兰克福那台测到 2.9%）。如果你主要用移动网络，先搞清线路对移动方向的处理方式，别只看宣传页上的“三网优化”。

明显不适合的情况也有两种。一种是每月流量几百 GB 以内、对带宽没要求的轻度用户，同价位法兰克福 9929 更划算；另一种是单纯建站、访客主要在国内的场景，普通欧洲 VPS（回程走 4837）大概率够用，9929 的溢价花不出效果。
